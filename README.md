# Google OAuth Authentication API

A modular FastAPI application for Google OAuth authentication with JWT token generation.

## Project Structure

```
Google_auth_tool/
├── app/
│   ├── __init__.py
│   ├── main.py              # Application entry point
│   ├── config.py            # Configuration and settings
│   ├── models.py            # Pydantic models
│   ├── routes/
│   │   ├── __init__.py
│   │   └── auth.py          # Authentication routes
│   └── utils/
│       ├── __init__.py
│       ├── jwt_utils.py     # JWT token utilities
│       └── google_oauth.py  # Google OAuth utilities
├── .env                     # Environment variables
├── .gitignore
├── main.py                  # Backward compatibility wrapper
└── README.md

```

## Features

- ✅ Google OAuth 2.0 authentication
- ✅ JWT token generation and validation
- ✅ Modular architecture with separation of concerns
- ✅ Type hints and Pydantic models
- ✅ Comprehensive error handling
- ✅ API documentation (auto-generated by FastAPI)

## Setup

1. Install dependencies:
```bash
pip install fastapi uvicorn python-jose[cryptography] python-dotenv requests pydantic[email]
```

2. Configure environment variables in `.env`:
```env
GOOGLE_CLIENT_ID=your_client_id
GOOGLE_CLIENT_SECRET=your_client_secret
GOOGLE_REDIRECT_URI=http://localhost:8000/auth/google/callback
JWT_SECRET_KEY=your_secret_key
```

3. Run the application:
```bash
uvicorn app.main:app --reload --host 0.0.0.0
```

## API Endpoints

- `GET /` - Root endpoint with API information
- `GET /auth/login/google` - Get Google OAuth login URL
- `GET /auth/google/callback` - Handle OAuth callback and return JWT token
- `GET /docs` - Interactive API documentation

## Module Overview

### `app/config.py`
Centralized configuration management using environment variables.

### `app/models.py`
Pydantic models for request/response validation.

### `app/utils/jwt_utils.py`
JWT token creation and verification utilities.

### `app/utils/google_oauth.py`
Google OAuth flow implementation (auth URL generation, token exchange, user info retrieval).

### `app/routes/auth.py`
Authentication API endpoints.

### `app/main.py`
FastAPI application initialization and router registration.
